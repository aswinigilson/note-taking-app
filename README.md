# Python Note-Taking App

A simple and user-friendly console-based Note-Taking Application developed using Python. This project demonstrates modular programming, object-oriented programming (OOP), and file handling using JSON for persistent data storage.

## Features

- **Add Notes:** Create notes with a title, content, and optional tags.
- **View Notes:** Display all saved notes with their timestamps and tags.
- **Search Notes:** Search notes by title, content, or keywords in tags.
- **Delete Notes:** Delete unwanted notes with confirmation through a cancellation option.
- **Filter by Tag:** Find notes based on specific tags.
- **Data Persistence:** Automatically save and load notes using a JSON file.
- **Error Handling:** Handle invalid inputs, missing files, and corrupted JSON data.

## How to Run the Project

**1. Clone the repository**

```bash
git clone https://github.com/aswinigilson/note-taking-app.git
```

**2. Navigate to the project directory**

```bash
cd note-taking-app
```

**3. Run the application**

```bash
python main.py
```
